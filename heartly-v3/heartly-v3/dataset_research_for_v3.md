# Dataset Research for Heartly v3

## What Did Heartly v2 Use? (12 datasets, ~247k samples)

| Domain | Datasets | Samples |
|--------|----------|---------|
| Factual QA | SQuAD v1.1, TriviaQA, Natural Questions Open, SciQ, BoolQ, WebQuestions | ~155k |
| Coding | CodeAlpaca-20k, Python Code Instructions 18k, MBPP | ~39k |
| Instructions | Dolly-15k, Alpaca | ~45k |
| Math | GSM8K | ~7.5k |

## What the Industry Actually Uses

I've analyzed what models like Llama 3, Mistral, Phi-3, Zephyr, and others have used. Here's what's missing from Heartly v2:

---

### 1. Reasoning & Chain-of-Thought (CRITICAL GAP)

Heartly v2 only had GSM8K for math reasoning. Modern models use MUCH more:

| Dataset | Size | Description |
|---------|------|-------------|
| **OpenMathInstruct** (NVIDIA) | 180k+ | Math problems with step-by-step reasoning in English |
| **MetaMathQA** | 395k | Math questions augmented with multiple reasoning paths |
| **MathInstruct** | 260k | Diverse math + reasoning tasks |
| **PRM800K** | 800k | Process reward model data for step-by-step verification |
| **DART-Math** | 25k+ | Hard math problems with reasoning |
| **NuminaMath-COT** | 860k | Large collection of math with chain-of-thought |
| **ARB** | 5.7k | Advanced reasoning benchmark (hard) |
| **LogiQA** | 8.5k | Logical reasoning questions |
| **ReClor** | 6.1k | Reading comprehension with logical reasoning |

### 2. Multi-turn Conversation (CRITICAL GAP)

Heartly v2 only trained on single-turn Q&A. No model today does that.

| Dataset | Size | Description |
|---------|------|-------------|
| **OpenAssistant Conversations (OASST1)** | 161k messages | Multi-turn hierarchical conversations, rated by humans |
| **ShareGPT** (filtered) | 90k+ | Real ChatGPT conversations (anonymized) |
| **UltraChat** | 1.5M+ | Large-scale multi-turn GPT-generated conversations |
| **LMSys Chatbot Arena** | 330k+ | Real user conversations with multiple models |
| **Capybara** | 17k | Long multi-turn conversations with personas |
| **WizardLM Evol-Instruct** | 250k | Multi-turn with evolving difficulty |
| **SlimOrca** | 518k | Filtered subset of OpenOrca, multi-turn |

## Proposed v3 Training Plan

```
Total target: ~1.5-2M samples (up from 247k)

Multi-turn conversation:  500k  (OASST1 + UltraChat sample)
Math reasoning:            600k  (OpenMathInstruct + MetaMathQA + GSM8K)
General instructions:      500k  (OpenOrca sample + FLAN v2 sample + Alpaca-GPT4)
Coding:                    150k  (Evol-CodeAlpaca + Magicoder + MBPP)
Factual QA:                200k  (SQuAD + TriviaQA + HotpotQA + FEVER)
Reasoning:                  50k  (LogiQA + ReClor)
Abstention data:            50k  (R-Tuning style + TruthfulQA + HaluEval)
Long context:               10k  (LongAlpaca sample)
High quality polish:        1k   (LIMA)

KB-rendered positives:      As in v2 (through DatasetRenderer)
KB boundary negatives:      As in v2 (through DatasetRenderer)
Silence examples:           As in v2 (through DatasetRenderer)
```

## Key Changes from v2

1. **Multi-turn conversations** — teaches the model to maintain context across turns
2. **More math reasoning** — critical for the <think> block to actually think step-by-step
3. **Dedicated abstention data** (R-Tuning, TruthfulQA, HaluEval) — directly trains the verify/stop mechanics
4. **Higher quality coding** (Evol-CodeAlpaca instead of basic CodeAlpaca)
5. **Fact verification** (FEVER) — trains verify-before-claim
6. **Multi-hop reasoning** (HotpotQA) — trains combining information across sources
7. **Longer context** — increase from 512 to at least 2048 tokens
8. **More total data** — ~5-10x more samples than v2
